# ai_1.0
AI sandbox experiments

## Projects

### 🃏 Texas Hold'em Poker CLI

A colorful terminal poker game with ANSI card art and AI opponents.

```bash
python -m poker
```

See [`poker/README.md`](poker/README.md) for full instructions.

### 🂡 Blackjack CLI

Classic blackjack against the dealer.

```bash
python -m blackjack
```

See [`blackjack/README.md`](blackjack/README.md) for full instructions.

### 🐰 Bunny Hop

A cute terminal game: navigate your bunny around a grid to collect carrots while dodging foxes. Arrow keys to move, foxes get faster every level.

```bash
python -m bunny_hop
```

See [`bunny_hop/README.md`](bunny_hop/README.md) for full instructions.
