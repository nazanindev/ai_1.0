# ai_1.0

An experimental repo for testing [flow](https://github.com/nazanindev/ai-flow), an AI agent harness using Claude Code's agentic flow to autonomously plan, implement, and ship features across phases.

## About

This repo is a sandbox for exploring what an AI agent can build end-to-end with minimal human intervention. Each phase targets a different problem domain to stress-test the harness across varied codebases and requirements.

## Phases

### Phase 1 — Python CLI Games

Simple terminal games generated by the agent to validate the basic build-and-ship loop.

| Game | Command | Description |
|------|---------|-------------|
| Texas Hold'em Poker | `python -m poker` | ANSI card art, AI opponents, full betting rounds |
| 5-Card Draw Poker | `python -m five_card_draw` | Interactive draw phase with AI opponents |
| Blackjack | `python -m blackjack` | Hit, stand, double down |
| Roulette | `python -m roulette` | European single-zero, 6 bet types |
| Pai Gow Tiles | `python -m pai_gow` | Ancient Chinese domino casino game |
| Bunny Hop | `python -m bunny_hop` | Grid game: collect carrots, dodge foxes |

Each game has its own `README.md` with full instructions.
