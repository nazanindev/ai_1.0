### Roulette CLI

European single-zero roulette. Bet on a number, color, parity, half, dozen, or column — then spin the wheel.

```bash
python -m roulette
```

Bet types and payouts:
- **Straight** (0-36) — pays 35:1
- **Color** (red/black) — pays 1:1
- **Parity** (even/odd) — pays 1:1
- **Half** (low 1-18 / high 19-36) — pays 1:1
- **Dozen** (1st/2nd/3rd) — pays 2:1
- **Column** (1st/2nd/3rd) — pays 2:1

See [`roulette/README.md`](roulette/README.md) for full instructions.
